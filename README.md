Clash Royal web-site

📌 About

A fan-made website dedicated to the Clash Royale game community. The site provides useful information for players and includes a registration flow for joining the community.

📄 Pages

Home — main landing page with an overview of the site

News — latest updates and game-related news

Clan Wars — analysis and breakdown of clan war battles

FAQ — answers to the most common questions

✨ Features

📱 Fully responsive — adapts to all screen sizes (mobile, tablet, desktop)

🔐 Registration modal — pop-up window for user sign-up

⚡ Fast and lightweight — built as a single-page application

🛠️ Tech Stack

React — component-based UI

Tailwind CSS — utility-first styling

Netlify — hosting and deployment
